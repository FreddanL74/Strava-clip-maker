Strava clip maker v1.6.1

Combine a GoPro video or time-lapse photos with a Garmin GPX or TCX file into a 30-second portrait time-lapse with overlays. Everything runs locally in your browser; no file leaves this computer.

2. What to show

Map background uses © OpenStreetMap contributors. In animated mode the map follows the GPS position. Only required tiles are cached for the selected clip. If unavailable, the original plain GPS map is used.

3. Sync video and data

Offset = seconds into the activity file at the first video frame or photo. It starts from the camera clock, which is often off by tens of seconds. Auto-sync matches image motion against speed. Check the result with the preview slider: the dot should stop when you stop.
